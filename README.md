# Chemie Mibaso

Lernpfad Chemie für die Vertretungsstunde: Säuren, Laugen, Salze und Bindungen – mit Laborpass, kurzen stummen Versuchsfilmen, Animationen und druckbarer Urkunde.

Live: https://chemie.mibaso.de

Neuauflage der Lernsoftware „ICU Multimedia Chemie“ (2002–2006) von Michael Baur. Die Seite wird bei jedem Push auf `main` automatisch über GitHub Actions veröffentlicht; dabei bekommt `sw.js` eine neue Versionsnummer, damit installierte Apps das Update laden.
