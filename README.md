# Chemie Mibaso

Lernpfad Chemie für die Vertretungsstunde: Säuren, Laugen, Salze und Bindungen – mit Laborpass, kurzen stummen Versuchsfilmen, Animationen und druckbarer Urkunde.

Live: https://chemie.mibaso.de

Neuauflage der Lernsoftware „ICU Multimedia Chemie“ (2002–2006) von Michael Baur. Veröffentlicht über GitHub Pages (Branch `main`, Hauptordner). Bei jeder Änderung die VERSION in `sw.js` hochzählen, damit installierte Apps das Update laden.
